# StyleMate - AI 패션 코디 추천 프로그램

## 📋 프로젝트 소개
OpenAI GPT와 실시간 날씨 API를 활용한 AI 기반 패션 코디 추천 프로그램입니다.
사용자 피드백(좋아요/나빠요)을 학습하여 점점 더 정확한 추천을 제공합니다.

## 🚀 설치 및 실행 방법

### 1단계: 필수 라이브러리 설치
```bash
pip install openai requests PySide6
```

### 2단계: API 키 발급
1. **OpenAI API 키**
   - https://platform.openai.com/api-keys 접속
   - 계정 생성 후 API Keys 메뉴에서 새 키 생성
   - 생성된 키(sk-로 시작)를 복사

2. **날씨 API 키** (무료)
   - https://openweathermap.org/api 접속
   - 무료 계정 생성 후 API keys 메뉴에서 키 확인
   - 생성된 키를 복사

### 3단계: 프로그램 실행
```bash
python main.py
```

### 4단계: 초기 설정
1. 사용자 이름 입력하여 로그인
2. 설정 페이지(⚙️)로 이동
3. OpenAI API 키와 날씨 API 키 입력
4. 기본 도시 설정
5. "API 테스트" 버튼으로 연결 확인
6. 저장 버튼 클릭

## 💡 주요 기능

### 1. AI 코디 추천 (✨)
- **GPT 추천 (고급)**: OpenAI GPT-4를 활용한 고급 추천
- **빠른 추천 (기본)**: 룰 기반 빠른 추천
- 실시간 날씨 정보를 반영한 추천
- 계절, 무드, 사용자 선호도 고려

### 2. 피드백 학습 시스템 (👍👎)
- **좋아요**: 선호하는 스타일을 학습하여 더 많이 추천
- **나빠요**: 해당 스타일/색상 조합을 피하도록 학습
- 최근 50개 피드백 저장 및 분석
- GPT 프롬프트에 자동 반영

### 3. 옷장 관리 (👕)
- 옷 등록 (이름, 카테고리, 색상, 무드, 계절)
- 자동 아이콘 표시
- 카테고리/색상 필터링
- 카드형 UI로 직관적 관리

### 4. 캘린더 & 다이어리 (📅)
- 날짜별 코디 기록
- 날씨, 기분, 메모 저장
- 직접 선택 또는 즐겨찾기에서 코디 선택
- 캘린더 위젯으로 쉬운 날짜 선택

### 5. 즐겨찾기 (⭐)
- 마음에 드는 코디 저장
- 스타일 통계 분석 (선호 색상, 스타일, 무드)
- 카드형 목록 표시

### 6. 사용자별 데이터 분리
- 여러 사용자가 독립적으로 사용 가능
- 각 사용자마다 별도의 데이터 폴더
- 로그아웃/로그인 기능

## 📊 데이터 구조

```
data/
├── users.json                    # 사용자 목록
├── current_user.txt              # 현재 로그인 사용자
├── settings.json                 # API 설정
└── users/
    └── [사용자이름]/
        ├── clothes.json          # 옷장 데이터
        ├── calendar.json         # 캘린더 데이터
        ├── favorite.json         # 즐겨찾기 데이터
        └── feedback.json         # 피드백 데이터
```

## 🎯 AI 추천 알고리즘

### GPT 추천 (고급 모드)
1. 사용자 옷장 데이터 수집
2. 현재 날씨 및 계절 정보 수집
3. 피드백 데이터 분석 (좋아요/나빠요)
4. GPT-4에게 다음 정보 제공:
   - 옷장 목록
   - 날씨/계절
   - 사용자 선호도 (좋아하는 스타일/색상)
   - 피하는 스타일/색상
5. GPT가 최적의 조합 추천
6. 실제 옷 객체와 매칭하여 반환

### 피드백 학습 시스템
```
좋아요 → 선호 스타일/색상 기록 → 다음 추천 시 우선 반영
나빠요 → 비선호 조합 기록 → 다음 추천 시 회피
```

## 🎨 UI/UX 특징

- **모던한 디자인**: 그라데이션 사이드바, 카드형 레이아웃
- **직관적인 네비게이션**: 이모지 아이콘 + 명확한 메뉴
- **실시간 피드백**: 날씨 정보, 학습 현황 표시
- **반응형 레이아웃**: 스크롤 가능한 컨텐츠 영역

## 🔧 문제 해결

### API 키 오류
- 설정 페이지에서 API 키 재확인
- "API 테스트" 버튼으로 연결 확인
- OpenAI 계정 크레딧 잔액 확인

### 날씨 정보 로드 실패
- 날씨 API 키 재확인
- 도시명이 올바른지 확인
- 네트워크 연결 확인

### 추천 결과 없음
- 옷장에 옷이 등록되어 있는지 확인
- 계절에 맞는 옷이 있는지 확인
- 무드/카테고리 설정 확인
